# LinkedIn carousel

Seven portrait slides prepared for a LinkedIn carousel. Upload the PNG files in numeric order (`01` through `07`). Each image is 1080 × 1350 pixels.

The SVG files are editable source artwork. Regenerate the complete set from the repository root with:

```bash
npm --prefix frontend run export:linkedin
```

The visual style uses square corners, restrained colors, serif headlines and monospaced data labels. The results slide labels the 2025 score as retrospective; the final slide also discloses the open macro-source rights review.
