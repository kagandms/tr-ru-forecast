# M13 Acceptance Report

## Scope and data provenance

M13 delivers a responsive Next.js executive analytics dashboard with five modules: KPI/provenance, trade and holdout explorer, champion/model lab, SHAP explainability, and mirror statistics. Its typed client supports `LIVE_API` mode and fallback to a SHA-256-verified static snapshot. The snapshot is generated by `make m13-export-snapshot` from the local read-only M12 service and records all 14 sectors, 42 tasks, 168 CV candidates, 1,512 role forecasts and 9,072 SHAP feature rows. Health request-time timestamps are omitted from this deterministic static projection; M10/M11 digest and readiness fields remain.

The evaluation scope remains `retrospective_latest_vintage_deterministic_lag`: historical latest-vintage trade and macro observations are evaluated under deterministic release-lag/origin cutoffs. This is not historical publication-time/vintage fidelity and does not establish live availability at each decision time. The explorer explicitly separates raw champion, operational forecast, fallback and seasonal-naive baseline. A champion that is invalid remains visible when governed fallback replacement is active.

PostgreSQL persistence and live online model serialization remain outside the frozen retrospective artifact-serving scope by design. No database, forward forecast, refit, model deserialization, or source refresh was added. Mirror observations are the paired reporters distributed by UN Comtrade; independently verified TurkStat and Rosstat files are not available in this bundle. CIF/FOB is described as a possible valuation discrepancy, not a freight adjustment estimate. Post-2022 paired structural comparison remains unavailable where no pairs exist.

## Contract change

The API `TaskComparison` response adds `selection_reason`, projected from the frozen M10 champion matrix, so `PARSIMONY_PREFERENCE` and `CLEAR_SMAPE_WINNER` can be displayed without reconstructing selection decisions in the browser. Candidate eligibility and negative CV forecast counters continue to come from the M10 candidate records.
