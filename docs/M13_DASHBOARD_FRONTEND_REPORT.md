# M13 Decision Support Dashboard

## Delivered interface

`frontend/src/app/page.tsx` provides five keyboard-accessible tab panels: executive KPIs and provenance; trade and holdout exploration; the 14×3 champion matrix plus candidate eligibility table; global/local XGBoost explainability; and mirror-data diagnostics. The explorer plots exact persisted history beside 2025 actual, operational, raw champion, fallback, seasonal-naive and selected interval series. Invalid champion values and governed replacement points are also retained in the month-level table.

The dashboard uses native SVG and CSS, strict TypeScript and the existing Next.js/React packages. API wire types live in `frontend/src/types/api.ts`. `frontend/src/lib/api.ts` loads M12 endpoints when `NEXT_PUBLIC_API_BASE_URL` is configured and checksum-verifies `public/data/snapshot.json` as the complete fallback. Snapshot payload dimensions and SHAP contribution counts are checked before the dashboard renders. The UI exposes the active source and SHA-256 in its header.

## Snapshot export and API contract

Run `make m13-export-snapshot` with the verified local M12 artifacts present. The exporter calls the read-only FastAPI service, collects all sectors, task comparisons, per-series forecasts, 42 explanation responses and all pages of mirror observations, then writes canonical sorted JSON and a SHA-256 manifest under `frontend/public/data/`. Request-time health timestamp is omitted because it is liveness metadata; frozen provenance and readiness counts remain. The manifest pins the generated bytes. The export is reproducible for identical source artifacts and serving code.

The M12 `TaskComparison` projection now includes its existing matrix `selection_reason`, so the interface can distinguish `CLEAR_SMAPE_WINNER` and `PARSIMONY_PREFERENCE`. It is a read-only field sourced from the frozen champion matrix; no processed data or model-selection output was changed.

## Interpretation constraints

The mirror panel identifies the UN Comtrade reporter pair and displays the API's paired-count limitations. It does not imply separate TurkStat/Rosstat source validation or estimate freight-only CIF/FOB effects. Post-2022 asymmetry remains unavailable when paired observations are absent. SHAP is labelled predictive attribution, not causal effect. Candidate leaderboard holdout columns refer to the operational task result, not challenger-specific holdout predictions.

The local production build was opened in the in-app browser; snapshot verification, executive KPIs, model matrix, explorer filters, and fallback diagnostics rendered. This is local browser smoke evidence only: no hosted deployment, authenticated integration, or real-user UAT was performed. Automated build and contract/integrity checks are recorded in `M13_ACCEPTANCE_REPORT.md`.
